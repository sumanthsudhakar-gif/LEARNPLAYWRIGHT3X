## Quick Reference — Most Used

```
Ctrl + P        → Quick Open / File search
Ctrl + Shift + P → All commands
Ctrl + `        → Toggle terminal
Ctrl + B        → Toggle sidebar
Ctrl + /        → Toggle comment
Alt + ↑ / ↓     → Move line
Ctrl + D        → Multi-select (repeat to select more)
F5              → Start debugging
F12             → Go to definition
```

---

## Pipeline: How a Keystroke Becomes an Action

```
Key Press
    ↓
VS Code registers the key combination
    ↓
Command lookup in keybindings.json
    ↓
Execute the registered command
    ↓
Result (cursor move, edit, panel toggle, etc.)
```
